Install

$ curl -fLo ageforge https://github.com/espresso20/ageforge/releases/latest/download/ageforge-macos-arm64 && chmod +x ageforge && ./ageforge

Apple Silicon. On an Intel Mac, swap in ageforge-macos-amd64.

Try it here first: type help, play, build hut, advance or map.

Other ways to install

Direct downloads from the latest release:

  • macOS, Apple Silicon
  • macOS, Intel
  • Linux, x86_64
  • Linux, ARM64
  • Windows, x86_64

macOS blocks a file downloaded in a browser: right-click it, choose Open, then Open Anyway, or run xattr -d com.apple.quarantine ageforge-macos-arm64. On Windows, use Windows Terminal; if SmartScreen warns you, choose More info, then Run anyway.

Build from source (Go 1.26 or newer):

git clone https://github.com/espresso20/ageforge.git
cd ageforge
go build -o ageforge .
./ageforge

Saves live in a data folder next to the binary. The install guide covers terminals, fonts and updates.
