# Badges: design docs

The spec for the badge build. Kept as written: this folder is an archive of the design, not a page that tracks the code. When the code and a doc here disagree, the code wins and the wiki (`site/docs/`) describes it.

| File | What it is | Status |

Ends with a 2026-10-01 addendum of owner requests (integrity badge art, the Source and Glitch themes, new palettes, the "We Are Not Alone" secret badge). | Approved spec for the upcoming badge build.
