# How this file is written (the same in every file of this folder):
#
#   A line that starts with # is a comment. Blank lines are skipped.
#
#   "== words NAME" starts a noun bank. Each line under it is one entry, written
#   as it lands in the middle of a sentence: lowercase, no full stop.
#
#   "== NAME" starts a pool of sentences. NAME is the pool's name. Add eras=
#   (ancient, feudal, industrial, digital, cosmic) or ages= (age keys) to hold
#   the pool to those eras or ages, with commas between them. With neither, the
#   pool fits every age.
#
#   Under a pool, one line is one sentence, written as "tags | text".
#     text  has no full stop (the game adds it) and at most one ~, where an
#           entry of the noun bank named by slot= goes. The game fills in
#           {subject}, {res}, {amt_res} and the other {placeholders}.
#     tags  a register (plain, wry or joke), a form if it has one (ledger,
#           complaint, overheard or notice) and a topic, then any of tone=,
#           kind=, need= and slot=, with commas between several values.
#
#   Lines are numbered by their place in the pool or bank, and the numbers are
#   the row ids of the copy sheets and of the VibeMode script. Add new lines at
#   the end of a pool: a line put in the middle renumbers every line after it.

# HarbingerWarning — the warning itself, and what the settlement did with it.
# Request.Kind carries the risk tier (TierNone .. TierHigh); see harbinger.go.
#
# The tier is the whole point of this Moment. Before the Industrial Age the
# player has no number to read, so the prose is the only gauge they get, and a
# "none" warning must never sound like a "high" one. Every sentence here is
# tagged with the tiers it honestly fits: one tier, or an adjacent pair when a
# reaction reads the same at both (people going back to work fits "nothing to
# fear" and "a little to fear" alike). A small tier-neutral pool keeps a zero
# Request grammatical and is kept small on purpose, so that a caller who sends
# a tier gets that tier's voice almost every time.
#
# Precision follows config.HarbingerDef.ForecastPrecision. Ancient and feudal
# pools are vague: omens, cries, charts. From the Industrial Age the medium
# publishes the odds, so those pools talk about the figure, the odds, the
# estimate, and never print one. TestHarbingerPrecisionVocabulary holds the
# early pools to it.
#
# The quotable copy (the crier's cry, the headline, the leaked memo) lives in
# the per-age pools at the end of this file, because it belongs to one
# speaker. The pools below are the settlement's side.
