# How this file is written (the same in every file of this folder):
#
#   A line that starts with # is a comment. Blank lines are skipped.
#
#   "== words NAME" starts a noun bank. Each line under it is one entry, written
#   as it lands in the middle of a sentence: lowercase, no full stop.
#
#   "== NAME" starts a pool of sentences. NAME is the pool's name. Add eras=
#   (ancient, feudal, industrial, digital, cosmic) or ages= (age keys) to hold
#   the pool to those eras or ages, with commas between them. With neither, the
#   pool fits every age.
#
#   Under a pool, one line is one sentence, written as "tags | text".
#     text  has no full stop (the game adds it) and at most one ~, where an
#           entry of the noun bank named by slot= goes. The game fills in
#           {subject}, {res}, {amt_res} and the other {placeholders}.
#     tags  a register (plain, wry or joke), a form if it has one (ledger,
#           complaint, overheard or notice) and a topic, then any of tone=,
#           kind=, need= and slot=, with commas between several values.
#
#   Lines are numbered by their place in the pool or bank, and the numbers are
#   the row ids of the copy sheets and of the VibeMode script. Add new lines at
#   the end of a pool: a line put in the middle renumbers every line after it.

# ExpeditionSuccess — a party was sent out and it worked.
#
# The log line directly above this one already says "<Name> succeeded. Loot:
# ..." with the amounts. So none of the sentences here say that it worked. They say what came
# back, who did not, what broke, what the map says now, what the town did about
# it, and who is already arguing over the share. See catalog.go for the rules.
#
# This file is also the VOICE REFERENCE for the other four Moments. What it is
# trying to be is a quartermaster's book rather than a book of aphorisms:
# circumstantial, often mundane, occasionally digressive, and funny by accident
# about one line in seven. The lengths swing on purpose — a four-word line next
# to a thirty-eight-word one — because uniform rhythm is what made the two
# previous versions of this catalog read as machine-written.

# --- slot banks --------------------------------------------------------------
#
# Noun phrases, lowercase, one tight category per bank. A slot swaps the detail
# in a sentence; it never changes what the sentence is about. Bank fragments
# inherit the eras of every skeleton that references them, so anything drawn on
# from the ungated pool has to be as true of a hunting party as of a boarding
# crew.
