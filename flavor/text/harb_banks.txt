# How this file is written (the same in every file of this folder):
#
#   A line that starts with # is a comment. Blank lines are skipped.
#
#   "== words NAME" starts a noun bank. Each line under it is one entry, written
#   as it lands in the middle of a sentence: lowercase, no full stop.
#
#   "== NAME" starts a pool of sentences. NAME is the pool's name. Add eras=
#   (ancient, feudal, industrial, digital, cosmic) or ages= (age keys) to hold
#   the pool to those eras or ages, with commas between them. With neither, the
#   pool fits every age.
#
#   Under a pool, one line is one sentence, written as "tags | text".
#     text  has no full stop (the game adds it) and at most one ~, where an
#           entry of the noun bank named by slot= goes. The game fills in
#           {subject}, {res}, {amt_res} and the other {placeholders}.
#     tags  a register (plain, wry or joke), a form if it has one (ledger,
#           complaint, overheard or notice) and a topic, then any of tone=,
#           kind=, need= and slot=, with commas between several values.
#
#   Lines are numbered by their place in the pool or bank, and the numbers are
#   the row ids of the copy sheets and of the VibeMode script. Add new lines at
#   the end of a pool: a line put in the middle renumbers every line after it.
