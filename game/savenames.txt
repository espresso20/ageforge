# The word lists a suggested name for a new save is put together from.
# game/savenames.go says how the lists are combined.
#
# A name becomes a file name, so every entry is letters and single spaces only:
# no apostrophe, hyphen, digit or other mark.
#
# How this file is written:
#
#   A line that starts with # is a comment. Blank lines are skipped.
#
#   "== NAME" starts a list, named for the variable in savenames.go that holds
#   it. Each line under it is one entry.
#
#   An entry written (none) is an empty word: the name is put together without
#   it. Its place in the list still counts.
#
#   Entries are numbered by their place in the list, and the numbers are the
#   row ids of the copy sheets (save_name.NAME.001). Add new entries at the
#   end of a list: one put in the middle renumbers every entry after it.

# Phrasings for the "of" names ("Republic of ..."), shared by the epic and the
# whimsical names.
